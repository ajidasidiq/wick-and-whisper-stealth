# Wick & Whisper — a candlelit stealth heist

A complete top-down stealth game for the make.fun best-stealth-game bounty.
You are Wick, a thief in the night: steal the golden candlesticks, slip past
the watchmen's vision cones, hide behind crates and bookshelves, linger in
the shadows, duck behind curtains — and reach the green exit door unseen.

- 3 manors, 2–4 patrolling watchmen each, with a detection meter that gives
  you a chance to recover: break line of sight and the alarm dies down
- WASD / arrows to move, click to walk there, hold Shift to sneak
- Relics, time bonuses and a ghost bonus for never raising the alarm
- Synthesized WebAudio sound: footsteps, guard boots, alarm stings, chimes
- No build step, no network requests: open `game/index.html` from any
  static server (or run `node serve.ts` and visit http://localhost:8080)

Built with plain JavaScript and Canvas 2D. Original art, names and sounds.
